# X (Twitter) Followers Scraper

Асинхронный парсер для сбора списка подписчиков с профилей X.com. Реализован с использованием **`curl_cffi`** для обхода TLS-отпечатков (JA3/JA4) и современных анти-бот систем.

### Технический стек и навыки
*   **Python / Asyncio:** Полностью асинхронная архитектура для высокой производительности.
*   **Bypassing Fingerprinting:** Использование `curl_cffi` (impersonate chrome110) для имитации реального браузера.
*   **Reverse Engineering:**
    *   Работа с внутренним **GraphQL API** (получение User ID).
    *   Работа с **REST API 1.1** (пагинация списка подписчиков).
*   **Error Handling:** Обработка Rate Limits (429) и автоматическая пауза.

### Установка и запуск

1. **Установите зависимости:**
   ```bash
   pip install curl_cffi
   ```

2. **Настройка:**
   Откройте файл и заполните константы своими данными:
   *   `PROXY`: Ваш прокси (http/https).
   *   `COOKIES`: Ваши `auth_token` и `ct0` из браузера.
   *   `TARGET_USERNAME`: Имя цели.

3. **Запуск:**
   ```bash
   python main.py
   ```

Результат будет сохранен в `followers_list.txt`.
